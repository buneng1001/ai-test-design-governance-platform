# 09 — 生成可追踪的候选测试用例

**What to build:** 测试工程师可基于已确认需求、范围、风险、自动化决定和模板映射运行用例生成，
获得可逐条复核、可追踪且保持合理用例粒度的候选测试用例。

**Blocked by:** 05 — 建立可审计 AI 运行与确定性 Mock；07 — 完成测试维度、范围、风险和自动化候选设计；
08 — 完成多工作表用例模板映射。

**Status:** resolved

- [x] 候选测试用例包含明确目标、前置条件、有序测试步骤、逐步预期、整体预期和证据要求。
- [x] 每条候选用例关联已确认的原子需求、测试范围项、风险项、测试优先级和用例归属表。
- [x] 不同边界、等价类、输入或场景形成可独立确认和执行的测试用例。
- [x] 用例设计依据作为内部审核信息保存，并与最终用例文件字段分离。
- [x] 无法通过模板无损表达的用例内容会提示测试工程师确认，不会静默丢失。
- [x] 一个或多个独立用例可关联同一自动化实现映射，但仍保留独立身份。
- [x] AI 输出无效或引用未确认资产时不创建候选用例。
- [x] API 测试验证生成、追踪完整性、用例粒度、模板表达限制和 Mock 失败行为。
- [x] 页面支持查看候选内容、追踪关系、设计依据和生成运行审计。

# 08 — 完成多工作表用例模板映射

**What to build:** 测试工程师可上传 XLSX 或 CSV 用例模板，检查工作簿结构，确认每张工作表的角色、标题行和字段映射，
从而在不绑定某个组织模板的前提下建立可验证的导入导出边界。

**Blocked by:** 01 — 建立本地应用骨架与测试设计项目闭环。

**Status:** resolved

- [x] XLSX 可列出全部工作表、候选标题行、列信息和可能影响导出的复杂特性。
- [x] AI 可建议工作表角色，但测试工程师必须确认用例表、说明表、字典表、统计表或未知。
- [x] 测试工程师可逐表选择是否参与处理，并为不同用例表确认不同标题行和模板映射。
- [x] 映射校验能识别缺失必需字段、重复映射、无法表达的内部语义和潜在数据损失。
- [x] CSV 作为单表模板进入同一确认流程。
- [x] 模板版本和确认映射不可被后续上传静默覆盖。
- [x] 契约往返测试验证多个用例表、不同映射、非参与工作表保留和明确的格式损失诊断。
- [x] 前端测试覆盖上传多工作表模板并完成逐表映射确认。

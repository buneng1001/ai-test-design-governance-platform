# 13 — 创建执行批次与人工执行文件

**What to build:** 测试工程师可从已发布测试任务创建执行批次，冻结本轮上下文和用例修订快照，
预分配不会重复的执行序号，并导出供人工填写的执行文件。

**Blocked by:** 12 — 发布通用 JSON/YAML 测试任务。

**Status:** resolved

- [ ] 执行批次记录产品版本、需求版本、环境、测试范围、负责人、执行目标和用例修订快照。
- [ ] 创建批次时为每个纳入的稳定用例 ID 预分配下一执行序号，重复请求不会覆盖既有序号。
- [ ] 执行展示编号由外部用例编号和执行序号组成，内部仍分别保存稳定用例 ID、修订版本和执行记录身份。
- [ ] 批次创建后，后续用例内容或状态变化不改变已冻结的本批次快照。
- [ ] 人工执行文件包含填写状态、实际结果、原因、人员、时间和证据引用所需字段。
- [ ] 人工执行文件按已确认模板或明确的通用格式生成，并能通过结果导入契约预校验。
- [ ] API 测试覆盖批次创建、空范围、重复请求、并发序号、快照不可变性和文件下载。
- [ ] 前端测试覆盖选择范围、创建批次和下载人工执行文件。

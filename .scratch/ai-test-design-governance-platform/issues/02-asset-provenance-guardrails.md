# 02 — 建立资产来源记录与洁净重写护栏

**What to build:** 让测试工程师在任何演示资产进入测试设计项目或模型上下文前登记来源、使用权限和内容哈希，
并阻止来源不明资产进入后续流程，以可观察证据落实洁净重写边界。

**Blocked by:** 01 — 建立本地应用骨架与测试设计项目闭环。

**Status:** ready-for-agent

- [ ] 测试工程师可为资产登记类型、来源或创建方式、使用权限、模型使用权限、需求版本和用途。
- [ ] 平台确定性计算并保存资产 SHA-256，内容变化后能够识别哈希不一致。
- [ ] 缺少必要来源或使用权限的资产被标记为来源不明资产，不能进入正式需求资料包或模型上下文。
- [ ] 原创合成、公开授权和禁止使用三类边界在 API 与页面中有明确结果和原因。
- [ ] 资产来源记录保留创建和变更历史，不能通过覆盖旧记录掩盖来源变化。
- [ ] API 测试验证允许、拒绝、哈希变化和模型上下文过滤行为。
- [ ] 不读取、扫描或导入任何原公司旧项目目录或资产。

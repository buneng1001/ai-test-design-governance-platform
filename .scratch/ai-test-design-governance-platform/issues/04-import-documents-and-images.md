# 04 — 扩展 DOCX、PDF 与截图需求资料

**What to build:** 在既有需求版本导入流程中支持 DOCX、可提取文本的 PDF、PNG 和 JPG，让文档内容与截图线索
进入统一来源引用体系，同时明确格式能力边界和视觉推断状态。

**Blocked by:** 03 — 导入文本与结构化需求资料并形成需求版本。

**Status:** resolved

- [x] DOCX 正文和可支持的表格内容可提取，并产生可复核的需求来源引用。
- [x] 可提取文本的 PDF 可导入；扫描版、加密、损坏或提取不完整的 PDF 给出明确诊断。
- [x] PNG、JPG 输入可形成带原始资产引用的视觉推断候选，不能直接成为已确认需求事实。
- [x] 文件类型、大小、内容哈希和解析状态均由确定性逻辑产生。
- [x] 需求版本页面统一展示文本、结构化资料、文档和图片的来源及解析结果。
- [x] 文件契约往返测试覆盖正常内容、空内容、损坏内容、部分解析和不支持特性。
- [x] 首版不承诺完整 OCR、复杂 PDF 版面还原或视频需求讲解处理。

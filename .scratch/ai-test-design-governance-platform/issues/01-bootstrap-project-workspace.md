# 01 — 建立本地应用骨架与测试设计项目闭环

**What to build:** 建立可本地启动的测试设计与治理平台最小纵向闭环。测试工程师能够通过浏览器创建、查看和编辑
测试设计项目及其测试对象，数据经公开 API 持久保存，并具备后续任务可复用的运行、迁移和测试基础。

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 使用项目约定的 Python、FastAPI、React、TypeScript、SQLite、Pytest 和 pnpm 建立最小可运行工程。
- [x] 测试工程师可以创建测试设计项目，填写名称、测试对象、描述和必要项目设置。
- [x] 刷新或重启本地服务后，已创建项目仍可通过 API 和页面查看、编辑。
- [x] 项目列表与项目工作台能够区分多个测试设计项目，并提供清晰的空状态和校验错误。
- [x] FastAPI 应用/API 边界测试覆盖创建、读取、修改、无效输入和不存在项目等外部行为。
- [x] 前端测试只验证创建项目并进入项目工作台的关键用户闭环。
- [x] 本地启动、测试和构建命令有简明说明，CI 可在无外部服务条件下运行基础检查。
- [x] 未引入登录、多人权限、设备控制、浏览器控制或测试执行能力。

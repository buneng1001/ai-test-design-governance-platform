# 05 — Step 01～02 结构预览与单一需求确认

**What to build:** 系统基于已解析材料分批识别功能与业务规则，用户只在一张按模块分组的需求确认表中查看、筛选、展开、勾选和确认需求。确认后的需求获得稳定 ID；未勾选项不会进入建议、测试设计、覆盖率或用例生成。

**Blocked by:** 01 — 项目专用 Skill 与结构化契约基线; 02 — AI 模型安全接入与连接验证; 04 — 上传文档与 Step 00 解析基线.

**Status:** ready-for-agent

- [ ] Step 01～02 按可控批次产生功能结构、业务规则和需求候选，每条正式候选具有有效来源引用和分析状态。
- [ ] 结构预览只出现一张需求确认表；原子拆分、来源引用、验收条件和分析说明只作为行摘要或展开详情展示。
- [ ] 用户可以按模块、类型、问题状态和关键字筛选，并对当前筛选结果批量选择或取消选择。
- [ ] 确认前明确显示已选、未选和阻塞问题数量，确认动作只处理当前明确选择的需求。
- [ ] 稳定需求 ID 只在确认后由确定性逻辑生成，重复打开、刷新和继续下游流程时保持不变。
- [ ] 未勾选需求不会进入新增建议的正式范围、测试项、测试点、候选用例、覆盖率分母和导出文件。
- [ ] AI 输出先经过结构、引用、唯一性和关系校验，失败时保留诊断，不创建看似成功的正式需求。
- [ ] 契约、API 和组件测试证明单表交互、验收条件展开、筛选勾选、稳定 ID 与未选择项隔离均有效。

**Out of scope:** 不在本任务生成 Step 03～06 建议、测试点或详细测试用例。

# 工程问题日志

## 使用规则

本日志只记录项目开发和验证中真实发生的问题。每条记录必须包含可观察证据、原因边界、处理和验证；
不得提前编造“踩坑”用于面试。

建议格式：

```md
## YYYY-MM-DD：问题标题

- 阶段：设计 / 实现 / 测试 / 演示
- 现象：可复现的客观表现
- 影响：受影响功能或交付物
- 证据：日志、失败测试、文件或截图链接
- 原因：已验证的原因；未确认部分明确标注
- 处理：最小修改及取舍
- 验证：命令、结果和剩余风险
```

## 2026-08-23：课程目录路径与显示路径不一致

- 阶段：设计
- 现象：用户提供的显示路径无法直接读取课程目录。
- 影响：课程能力映射无法建立。
- 证据：指定 Obsidian 根目录下存在
  `D:\Word\Obsidian\buneng1001_Obsidian_valut\20_Sources\AI自动化全栈课程目录.md`。
- 原因：消息中的下划线转义使目录层级显示与磁盘实际名称不同。
- 处理：只在用户指定的 Obsidian 根目录下按精确文件名查找，没有扫描无关资料。
- 验证：课程目录成功读取，模块和主题已进入课程应用映射。

## 2026-08-23：Windows 沙箱中 rg 无法启动

- 阶段：设计
- 现象：只读文件枚举时 `rg.exe` 返回拒绝访问。
- 影响：无法使用首选的快速搜索工具。
- 证据：PowerShell 返回进程启动拒绝访问，而非仓库内容错误。
- 原因：当前 Windows 沙箱进程权限限制。
- 处理：改用 `Get-ChildItem` 完成限定目录内的只读查找，没有扩大文件访问范围。
- 验证：项目目录、课程目录和授权参考文件均成功定位。

## 2026-08-24：Windows 沙箱阻止测试临时目录和 Vite 子进程

- 阶段：实现
- 现象：Pytest 清理项目内临时目录返回 `WinError 5`，Vite/Vitest 启动子进程返回 `spawn EPERM`。
- 影响：任务 02 的后端 API 测试、前端测试和生产构建不能在默认沙箱内完成。
- 证据：默认命令分别停在 pytest 临时目录清理和 Vite `externalize-deps` 配置加载阶段，尚未执行代码断言。
- 原因：Windows 沙箱进程和目录权限限制；不是用例失败、TypeScript 错误或依赖缺失。
- 处理：使用独立 pytest 临时目录，并在用户批准后以相同测试/构建命令在沙箱外重试，没有修改权限或清理目录。
- 验证：任务 02 API 测试、完整后端测试、前端关键闭环测试和生产构建结果见任务 02 完成记录。

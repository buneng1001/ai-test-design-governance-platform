# Triage labels

| Engineering skill 角色 | 本项目状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者分类和判断 |
| `needs-info` | `needs-info` | 等待补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或决策 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 skill 提到某个 canonical triage 角色时，使用本表对应的状态字符串。

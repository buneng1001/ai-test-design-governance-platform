## 明确禁止

- 原公司代码、Prompt、页面、截图、需求、接口、数据、日志和文档。
- 将真实资料改名、删字段或模糊数值后作为“合成数据”。
- 把工作总结中的真实版本、协议阈值和缺陷数据写入演示资产。
- 未确认许可证的公开数据集或模板。
- 把评估真值发送给被评价的模型。

## 更新要求

生成具体资产后，用仓库相对路径替换描述名称，补充创建日期、作者、需求版本、许可说明和 SHA-256；若文件内容变化，
必须更新哈希和变更原因。

## 本 ticket 的具体资产

`data/synthetic/smart-collector/asset-manifest.json` 是可重复校验的来源登记；
每条记录包含创建方式、作者、日期、用途、需求版本、模型使用范围和实际 SHA-256。
独立评估真值位于单独目录；即使客户端登记了允许模型使用，后端仍会在 AI 运行边界拒绝它。

## 平台护栏

- 在项目工作台登记资产类型、来源或创建方式、使用权限、模型使用权限、需求版本、用途和资产内容。
- 后端只依据收到的原始字节确定性计算 SHA-256，不信任客户端提供的哈希。普通资产不保存登记时的内容；评估真值
  仅为独立评估在后端隔离保存，不能进入普通模型上下文、API 响应、报告或导出物。
- 原创合成且项目自有、或公开授权且具有公开许可的需求资料，可以进入需求资料包；模型权限须单独明确允许。
- 评估真值始终与普通模型上下文隔离，即使登记时误选“允许”也不会放行。
- 禁止使用、来源为空、权限未知或来源边界与权限不一致时，资产不能进入正式需求资料包或模型上下文。
- 修改来源信息或内容时新增修订记录。哈希校验使用最新修订，并可通过历史 API 复核旧记录。
